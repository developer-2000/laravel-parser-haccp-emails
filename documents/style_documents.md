# Оформление документации

**Читабельность на высшем уровне.** Все пункты — с переносами строк.

- **Никогда** не писать весь текст в одну строку.
- **Каждый пункт** — с переносами: если в пункте несколько подпунктов или перечисление — разбивать на отдельные строки.
- Использовать **переносы строк** между смысловыми блоками.
- Списки и перечисления — только **маркированные/нумерованные списки**, каждый элемент с новой строки.
- Длинные формулировки внутри одного пункта — разбивать на строки, а не тянуть в одну линию.

## Примеры

**Хорошо:**
- Задачи:
    - Настроить роут
    - Добавить форму
    - Подключить API
    - Обновить стили

**Хорошо:**
Короткие абзацы. Каждая мысль — отдельный блок. Списки — через дефис или цифры.
